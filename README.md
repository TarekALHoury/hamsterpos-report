# HamsterPOS Reports

A lightweight Windows desktop reporting application for HamsterPOS.

## Features

- Product Sales Report
- Purchased Products Report
- Close Cash Movement Report
- Date, category, payment method, reason, and product filters
- Search by barcode, product name, or reference
- Historical sales and purchase pricing
- Discount and price-change indicators
- Category grouping with category subtotals
- Payment-method totals
- Light and dark appearance modes
- PDF export
- Configurable currency symbol
